# 중국어 발음 체크 (휴대폰 앱)

중국어 성조·발음 피드백 앱. GitHub Pages로 배포되며, 휴대폰에서 "홈 화면에 추가"하면 앱처럼 설치됩니다.

## 휴대폰에 설치
- **안드로이드 (Chrome)**: 앱 주소 접속 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰 (Safari)**: 앱 주소 접속 → 공유 버튼 → **홈 화면에 추가**

처음 실행할 때 마이크 권한을 허용해야 발음 체크가 됩니다.

## 참고
- 음성 인식: 안드로이드 Chrome 권장
- 번역 탭: 브라우저 내장 번역(Translator API)을 쓰므로 휴대폰 브라우저에서는 동작하지 않을 수 있습니다.
- `shared/` 폴더는 `Studying_Chinese/입문학습`의 스타일·단어 데이터를 복사한 것입니다.
